# Java GUI Event Listener Examples\n\nJava Swing을 이용한 GUI 이벤트 리스너(Event Listener) 예제 모음입니다.\n\n## 📁 프로젝트 구조\n\n```\nsrc/\n├── ActionListenerExzmple.java      # ActionListener 예제\n├── App.java                         # 메인 진입점\n├── FlyingTextEx.java                # KeyListener 예제 (텍스트 움직임)\n├── ItemListenerExample.java         # ItemListener 예제 (체크박스)\n├── Jlabel.java                      # JLabel 클래스\n├── KeyListenerEx.java               # KeyListener 예제\n├── MouseAdapterEx.java              # MouseAdapter 예제\n├── MouseClickExample.java           # 마우스 클릭 이벤트 예제\n├── MouseMotionExample.java          # MouseMotionListener 예제\n├── MyActionListener.java            # ActionListener 예제\n└── WindowCloseExample.java          # WindowListener 예제\n```\n\n## 🎯 예제 설명\n\n### 1. ActionListener (액션 이벤트)\n- **ActionListenerExzmple.java**: 버튼 클릭 시 라벨 텍스트 변경\n- **MyActionListener.java**: 버튼 클릭 시 텍스트 토글 예제\n\n### 2. ItemListener (아이템 이벤트)\n- **ItemListenerExample.java**: 체크박스 선택 시 버튼 활성화/비활성화\n\n### 3. KeyListener (키보드 이벤트)\n- **KeyListenerEx.java**: 키 입력 정보 표시 (KeyCode, KeyChar, KeyText)\n- **FlyingTextEx.java**: 화살표 키로 텍스트 움직이기\n\n### 4. MouseListener / MouseMotionListener (마우스 이벤트)\n- **MouseAdapterEx.java**: 마우스 클릭 위치로 텍스트 이동\n- **MouseClickExample.java**: 마우스 클릭 이벤트 감지\n- **MouseMotionExample.java**: 마우스 움직임(Move/Drag) 추적\n\n### 5. WindowListener (윈도우 이벤트)\n- **WindowCloseExample.java**: 윈도우 종료 시 확인 대화상자\n\n## 🚀 실행 방법\n\n각 Java 파일을 컴파일하고 실행합니다:\n\n```bash\n# 컴파일\njavac src/*.java\n\n# 실행 예제\njava -cp src ActionListenerExzmple\njava -cp src MyActionListener\njava -cp src ItemListenerExample\njava -cp src KeyListenerEx\njava -cp src FlyingTextEx\njava -cp src MouseAdapterEx\njava -cp src MouseClickExample\njava -cp src MouseMotionExample\njava -cp src WindowCloseExample\n```\n\n## 📚 학습 포인트\n\n- Swing 컴포넌트 (JFrame, JButton, JLabel, JCheckBox 등)\n- 다양한 이벤트 리스너 인터페이스\n- 익명 클래스를 이용한 리스너 구현\n- 어댑터 클래스 (KeyAdapter, MouseAdapter, WindowAdapter)\n- 람다식을 이용한 리스너 구현\n\n## 💻 요구 사항\n\n- Java 8 이상\n- Swing 라이브러리\n\n## 📝 라이선스\n\nEducational Purpose\n
